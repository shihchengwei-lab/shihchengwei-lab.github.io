What the authors did next

Dify · Queue reliability

A queue fix still left two handoff gaps.

I flagged two cases that could leave queued work stalled or handled by conflicting workers. The author confirmed both as blockers. The PR later closed without merging.

My review · #46310 Author’s response · #46310

Apache DataFusion · Query ordering

A query returned rows in the wrong order.

I reported a small example that returned two rows out of order. The author reproduced it and opened a separate fix with tests.

Author’s response · #27597

Apache Iceberg Go · Write retries

A retry reported failure after the write succeeded.

My test showed that a client could report a failed save even though the server had already applied the write. The author updated the retry logic so it reports an uncertain outcome when it can no longer verify the write.

Author’s response · #2679

Apache Flink · Saved query plans

A query ran directly but failed from a saved plan.

I checked both execution paths. The author confirmed that loading the saved plan picked the wrong function signature and said they would try a separate fix.

Author’s response · #30080

Apache Spark · SQL diagnostics

A SQL error pointed to the wrong line.

I found a mismatch in where the parser marked the error. The author corrected the highlighted location and added tests for both execution paths.

Author’s response · #60724

ClickHouse · Query correctness

A query could skip matching rows.

I flagged a mismatch between the query and its text index. The author confirmed the missing rows, fixed the PR, and added a regression test.

Author’s response · #133245

How I counted the reviews

I use AI to explore code paths and check claims against the source. I run focused tests in isolation where practical and send feedback when I have a specific point the author can check.
